Signal chain

  1. Python UI sends a 3-byte command per channel over USB-UART (115200 baud)
  2. Spartan-7 FPGA turns commands into SPI on 6 PMOD ports, re-mapped so every pin carries a signal
  3. Master PCB routes the bus to 16 MAX11300 DACs (16 × 20 = 320 outputs, 0–10 V)
  4. 7 ribbon cables carry 128 channels to the client PCB
  5. OPA chip: each DC voltage heats a phase shifter; the phase gradient steers the beam
  6. IR camera scores the beam and the genetic algorithm picks the next voltage set
