# Jordan Vick · Engineering Portfolio

Live site: https://jordankylevick-sudo.github.io/Portfolio_JV/

Static site (HTML/CSS/JS, no build step). Projects:

- **128-Channel Optical Phased Array Controller** (NRC Nanophotonics, 2024): `projects/opa-controller.html`, with the interactive three.js model in `opa-3d/`
- **PID Battery Temperature Regulation** (Queen's Relectric, 2023): `projects/temperature-regulation.html`, with a live PID simulator in `assets/pid.js`

To add a project: copy one of the pages in `projects/`, add its images to `assets/img/`, and add a card to `index.html`.
